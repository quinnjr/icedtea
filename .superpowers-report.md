* **`ImageCache` keyed by `(base_dir, url)`, with base-dir resolution and no
  permanent negative cache** — VERIFIED-FIXED, `ui/src/paint/mod.rs`. A
  relative `url()` was resolved against the process's working directory and
  the cache keyed on the URL alone, so a relative URL missed entirely or,
  after a theme swap, served the previous theme's bitmap; and a miss was
  remembered forever, so an image that arrived after the first frame never
  painted. Tests:
  `the_image_cache_resolves_relative_urls_against_its_base_directory`,
  `a_cache_miss_is_not_permanent`,
  `two_base_directories_do_not_share_a_relative_urls_pixels`. Wired from

* **Default radial-gradient ellipse radii (corner extents per axis)** —
  VERIFIED-FIXED, `ui/src/paint/background.rs::radial_radii`. CSS Images L3
  §3.2 gives a corner-sized *ellipse* `side * sqrt(2)` per axis; both
  corner arms used one circular `hypot(sx, sy)`, making every such ellipse a
  circle. The circle arm keeps the true corner distance. Test:
  `an_ellipse_sized_to_a_corner_is_not_a_circle`. **This diverges from wave
  A's newly exported `css::value::image::radial_radii`, which still uses the
  corner distance on both axes — see H6 in the handoff.**
* **Surface sizing: buffer/damage/hit-test cover the ink rect** —
  VERIFIED-FIXED, `Button::ink_rect`, `paint::shadow::outset_shadow_ink_rect`,
  `paint::outline::outline_ink_rect`, `LayerWindow::open`/`repaint`,

  did not have. The ink rect is built from the same numbers the painters use
  (including `blit_blurred`'s sigma cap), is never smaller than the border
  box, and the hit test shifts with the render origin. Tests:
  `the_ink_rect_covers_an_outset_shadow_and_an_offset_outline`,
  `the_ink_rect_is_the_border_box_when_nothing_paints_outside_it`,

  With the feature off, `FontDatabase::new` *is* `probe_only`, which is

  `ui/src/paint/shadow.rs`. `blit_blurred` takes a content key and consults a
