## Deviations from the spec, and why

These are decided. Do not relitigate them; implement them.

1. **Rect-in-toplevel-tree, not `raise_rect`.** The spec offered either. Parenting the SSD rect into the toplevel's per-toplevel `wlr_scene_tree` (`Runtime::add_rect_in_toplevel`) makes z-order structurally correct — the band cannot desynchronize from its toplevel again — where `raise_rect` would leave two nodes to keep ordered forever. Child-node coordinates are **relative to the toplevel tree's origin** (= the toplevel's content-space position), so the band sits at `(bar.x - content.x, bar.y - content.y)` = `(0, -TITLE_BAR_HEIGHT)`.
2. **Layer-shell handler methods live on `ToplevelHandler`.** `Handlers`' supertrait list froze at 0.20.1 (adding a supertrait breaks every existing consumer; adding defaulted methods to a declared trait does not). `ToplevelHandler` is the shell-surface trait, so layer-surface lifecycle methods (`new_layer_surface`, `layer_surface_commit`, `layer_surface_mapped/unmapped/destroyed`) are added there with a `layer_` prefix, fully defaulted.
3. **Buffer nodes take owned RGBA8888 pixels.** One format (`DRM_FORMAT_ABGR8888` — bytes R,G,B,A in memory), copied in, no damage tracking API, no dmabuf. Both consumers (wallpaper, title text) produce owned RGBA in worker/UI code; anything fancier is YAGNI and would freeze a bigger surface.
4. **Wallpaper scaling is stretch-to-output** via `set_buffer_dest_size`. `Appearance` has no scaling-mode field (verified), so there is nothing to honor; stretch is the baseline-parity behavior for the only mode that exists.
5. **Title text uses the system font via `cosmic-text`'s `fontdb` system loading**; color is `appearance.palette.foreground`. No font config field exists (verified) and adding one is out of scope. `FontSystem` lives in a `std::cell::OnceCell` inside `State` — constructed on first SSD title rasterization, never in a hot path.
6. **Workspaces stay global across outputs.** The spec's "workspaces … become per-output" is scoped down: the baseline model was single-output and its workspace list global; per-output workspace lists would be a model redesign beyond parity. M2 multi-output means: per-output wallpaper nodes, new-window placement on the output containing the pointer, and window migration off hot-removed outputs.
7. **`KeyEvent::for_test` constructs a `KeyEvent<'static>`.** The borrow lifetime is phantom (verified: `KeyEvent` carries `PhantomData`); a test constructor tied to no keyboard is sound and lets consumers unit-test `SeatHandler::key` without a device.
8. **Client-request policy for interactive move/resize:** `request_move`/`request_resize` are honored only while `State` has seen the pointer pressed (new `pointer_pressed: bool` field maintained in `SeatHandler::pointer_button`) — the protocol's serial-validation intent without a serial-plumbing API. Unhonored requests are ignored (protocol-legal).
9. **The bare-configure reply** `reconcile_maximized`/`reconcile_fullscreen` were designed around (`false` ⇒ "answer with a bare configure") is `Runtime::configure_toplevel(id)` → `wlr_xdg_surface_schedule_configure`, published in 0.20.7 alongside the request methods that need it.
10. **The harness observes through the existing command/event channels, not D-Bus.** Tests assert via `DbCommand::GetState` round-trips and the `contract::Event` stream (`dbus_tx`), and stop the loop via `DbCommand::Quit` + the command wake pipe — the exact production control plane minus the bus. No test bus daemon dependency.

```rust
#[test]
fn removing_a_live_source_stops_its_callbacks() {
    // Registers two pipes, wakes both, removes one from inside its own
    // fd_ready, wakes both again, and asserts the removed source never
    // fires after removal while the surviving one does.
    headless_env();
    use std::io::Write;
    struct App {
        runtime: wlr::Runtime,
        doomed: wlr::SourceId,
        doomed_fires: u32,
        survivor_fires: u32,
        turns: u32,
    }
    impl wlr::OutputHandler for App {}
    impl wlr::ToplevelHandler for App {}
    impl wlr::SeatHandler for App {}
    impl wlr::FdHandler for App {
        fn fd_ready(&mut self, source: wlr::SourceId, fd: std::os::fd::BorrowedFd<'_>, _r: wlr::Readiness) {
            let mut buf = [0u8; 16];
            let _ = rustix::io::read(fd, &mut buf); // drain so level-triggering stops
            if source == self.doomed {
                self.doomed_fires += 1;
                assert_eq!(self.runtime.remove_fd(self.doomed), Some(()));
            } else {
                self.survivor_fires += 1;
            }
        }
    }
    impl wlr::LoopHandler for App {
        fn should_stop(&mut self) -> bool { self.turns += 1; self.turns > 8 }
    }

    let display = wlr::Display::new().expect("display");
    let runtime = wlr::Runtime::new().expect("runtime");
    let backend = wlr::Backend::autocreate(&display.event_loop()).expect("backend");
    let (dr, mut dw) = std::io::pipe().expect("pipe");
    let (sr, mut sw) = std::io::pipe().expect("pipe");
    let doomed = runtime.add_fd(dr.into(), wlr::Interest::READABLE);
    let _survivor = runtime.add_fd(sr.into(), wlr::Interest::READABLE);
    dw.write_all(b"x").expect("wake doomed");
    sw.write_all(b"x").expect("wake survivor");
    let mut app = App { runtime: runtime.clone(), doomed, doomed_fires: 0, survivor_fires: 0, turns: 0 };
    backend.run_all(&display, &mut app, &runtime, wlr::Until::Turns(4)).expect("first run");
    dw.write_all(b"y").expect("second wake doomed");
    sw.write_all(b"y").expect("second wake survivor");
    backend.run_all(&display, &mut app, &runtime, wlr::Until::Turns(4)).expect("second run");
    assert_eq!(app.doomed_fires, 1, "removed source must not fire again");
    assert!(app.survivor_fires >= 2, "surviving source must keep firing");
}
```

```rust
const DRM_FORMAT_ABGR8888: u32 = 0x3432_4241; // fourcc('A','B','2','4'): bytes R,G,B,A

#[repr(C)]
struct PixelBuffer {
    base: sys::wlr_buffer,      // C base MUST be field 0 (container_of-free casts)
    stride: i32,
    data: Vec<u8>,
}

unsafe extern "C" fn pixel_destroy(buffer: *mut sys::wlr_buffer) {
    // SAFETY: `buffer` is the first field of the PixelBuffer we leaked in
    // `new`, so the cast recovers the original Box allocation, exactly once —
    // wlroots calls destroy exactly once, when the last lock is released.
    drop(unsafe { Box::from_raw(buffer.cast::<PixelBuffer>()) });
}

unsafe extern "C" fn pixel_begin_data_ptr_access(
    buffer: *mut sys::wlr_buffer, _flags: u32,
    data: *mut *mut std::ffi::c_void, format: *mut u32, stride: *mut usize,
) -> bool {
    // SAFETY: same layout argument as pixel_destroy; wlroots brackets this
    // with end_data_ptr_access and does not hold the pointer past it.
    let pb = unsafe { &mut *buffer.cast::<PixelBuffer>() };
    unsafe {
        *data = pb.data.as_mut_ptr().cast();
        *format = DRM_FORMAT_ABGR8888;
        *stride = pb.stride as usize;
    }
    true
}

unsafe extern "C" fn pixel_end_data_ptr_access(_buffer: *mut sys::wlr_buffer) {}

static PIXEL_BUFFER_IMPL: sys::wlr_buffer_impl = sys::wlr_buffer_impl {
    destroy: Some(pixel_destroy),
    get_dmabuf: None,
    get_shm: None,
    begin_data_ptr_access: Some(pixel_begin_data_ptr_access),
    end_data_ptr_access: Some(pixel_end_data_ptr_access),
};
```

```rust
pub fn rasterize_title(
    fonts: &mut cosmic_text::FontSystem, swash: &mut cosmic_text::SwashCache,
    text: &str, width: i32, height: i32, pad_x: i32, fg: [u8; 4],
) -> Option<Vec<u8>> {
    if width < 1 || height < 1 { return None; }
    use cosmic_text::{Attrs, Buffer, Family, Metrics, Shaping};
    let font_px = (height as f32 * 0.55).max(8.0);
    let metrics = Metrics::new(font_px, height as f32);
    let mut buffer = Buffer::new(fonts, metrics);
    let mut buffer = buffer.borrow_with(fonts);
    buffer.set_size(Some((width - pad_x).max(1) as f32), Some(height as f32));
    buffer.set_text(text, &Attrs::new().family(Family::SansSerif), Shaping::Advanced);
    buffer.shape_until_scroll(true);
    let mut px = vec![0u8; (width as usize) * (height as usize) * 4];
    let mut drew = false;
    buffer.draw(swash, cosmic_text::Color::rgba(fg[0], fg[1], fg[2], fg[3]), |x, y, w, h, color| {
        for dy in 0..h as i32 {
            for dx in 0..w as i32 {
                let (tx, ty) = (x + dx + pad_x, y + dy);
                if tx < 0 || ty < 0 || tx >= width || ty >= height { continue; }
                let i = ((ty * width + tx) * 4) as usize;
                let a = color.a();
                if a == 0 { continue; }
                drew = true;
                // straight-alpha over-blend onto transparent black
                px[i] = color.r(); px[i + 1] = color.g(); px[i + 2] = color.b();
                px[i + 3] = px[i + 3].max(a);
            }
        }
    });
    if drew { Some(px) } else { None }
}
```
