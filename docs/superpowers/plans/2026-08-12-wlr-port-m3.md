## Deviations / decisions of record

Decided; implement, do not relitigate.

1. **`add_rect_in_band` takes a new public `Band` enum, not the 4-variant `Layer`.** The scene has five bands (background/bottom/**toplevel**/top/overlay); `Layer` (layer-shell) has only four and semantically means "a layer-shell client's layer." A rect band selector that can name the toplevel band needs its own type: `pub enum Band { Background, Bottom, Toplevel, Top, Overlay }`. Internally it maps onto the existing `background_band`/…/`overlay_band` fields (and `toplevel_band`).
2. **The snap preview goes in `Band::Overlay`.** It must render above every window and every panel. Today `add_rect` parents at the scene root, which lands *above* the overlay band too and (per M2 finding I6) participates in pointer hit-testing. Overlay-band placement fixes the z-relationship; the acceptance test (Task 3) is that a click passes through to the window underneath — if band-parenting alone does not make the rect input-inert, the fix extends into the `leaf_surface_at` pointer hit-test to skip non-surface rect nodes, and the implementer follows the failing test to that conclusion rather than assuming.
3. **Config reload preserves rows by diffing, not rebuilding.** Task 4 stops replacing `self.window_manager` wholesale. The pinned M2 tests that asserted the old destroy-and-floor behavior (`apply_config_emits_window_closed_and_floors_id_counter`, `apply_config_rebuilds_workspaces`) are **rewritten** to assert the new preserve-and-rethemed contract — this is a deliberate contract change the spec sanctions, not a regression.
4. **Oversized migrated windows center.** Task 8 replaces `migrate_windows_from`'s corner-pin branch (`if geometry.width >= survivor.width { survivor.x }`) with centering: `survivor.x + (survivor.width - geometry.width) / 2` (which is ≤ 0 for oversized, placing the window centered and overflowing symmetrically), guarded so no `clamp` with inverted bounds is ever called.
5. **`WindowUpdate` gains `mapped: bool` as the last field.** The frozen wire signature `(asa(iiii)auabababab)` becomes `(asa(iiii)auababababab)` (one more `ab` = `Option<bool>`). The `wire_signatures_are_locked` test (`contract/src/types.rs:125`) is updated deliberately, per its own comment.
