# wlr port M4.1 — Selection stack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make clipboard copy/paste and primary (middle-click) selection work between Wayland clients, and expose the `zwlr_data_control_manager_v1` global so a clipboard manager can attach.

**Architecture:** wlroots implements the selection protocols server-side and auto-delivers offers to the keyboard-focused client. The `wlr` crate gains two manager-creation methods and wires the seat's `request_set_selection` / `request_set_primary_selection` events (today dropped) to `wlr_seat_set_selection` / `wlr_seat_set_primary_selection`. The compositor only creates the two new globals at boot; selection-follows-focus already works through the existing keyboard-focus path. Everything is verified by automated two-client wire-level tests.

**Tech Stack:** Rust, wlroots 0.20 via the `wlr` crate, `wayland-client` 0.31 / `wayland-protocols` 0.32 (unstable) / `wayland-protocols-wlr` 0.3 for the test clients.

**Spec:** `docs/superpowers/specs/2026-08-13-wlr-port-m4.1-selection-stack-design.md`

```rust
    /// paste). Wire the seat's `request_set_primary_selection` event to honor it
    /// (done in the backend registration). Errors if called twice.
    pub fn create_primary_selection_manager(&self, display: &Display) -> Result<()> {
        if self.inner.primary_selection_manager.borrow().is_some() {
            return Err(Error::Operation(
                "Runtime::create_primary_selection_manager called twice",
            ));
        }
        // SAFETY: `display` is live for the call; the returned manager is owned by
        // the display and destroyed with it, so this crate never frees it.
        let raw = unsafe { sys::wlr_primary_selection_v1_device_manager_create(display.as_ptr()) };
        let raw = NonNull::new(raw)
            .ok_or(Error::Create("wlr_primary_selection_v1_device_manager_create"))?;
        *self.inner.primary_selection_manager.borrow_mut() = Some(raw);
        Ok(())
    }

        &self,

        *self.inner.primary_selection_manager.borrow()
```

```rust
/// Honors a focused client's request to own the clipboard selection.
/// wlroots only fires this with a valid client grant serial, so accepting
/// as-delivered is the standard, correct behavior.
unsafe extern "C" fn on_request_set_selection<S: Handlers>(
    listener: *mut sys::wl_listener,
    data: *mut core::ffi::c_void,
) {
    let bound = unsafe { bound_of(listener) };
    let session = unsafe { &*(bound.session as *const Session<'_, S>) };
    let event = data.cast::<sys::wlr_seat_request_set_selection_event>();
    if let Some(seat) = session.runtime.seat_ptr() {
        // SAFETY: `seat` is the live seat that emitted this event; `event` is
        // wlroots-owned and valid for the callback; source/serial are copied out.
        unsafe {
            sys::wlr_seat_set_selection(seat.as_ptr(), (*event).source, (*event).serial);
        }
    }
}

unsafe extern "C" fn on_request_set_primary_selection<S: Handlers>(
    listener: *mut sys::wl_listener,
    data: *mut core::ffi::c_void,
) {
    let bound = unsafe { bound_of(listener) };
    let session = unsafe { &*(bound.session as *const Session<'_, S>) };
    let event = data.cast::<sys::wlr_seat_request_set_primary_selection_event>();
    if let Some(seat) = session.runtime.seat_ptr() {
        // SAFETY: as above.
        unsafe {
            sys::wlr_seat_set_primary_selection(seat.as_ptr(), (*event).source, (*event).serial);
        }
    }
}
```

```rust
/// Requests the current selection for `mime`, drives the roundtrip, and reads
/// the transferred bytes to EOF. Assumes this client currently has keyboard
/// focus so the compositor has delivered a wl_data_offer.
pub fn receive_selection(&mut self, mime: &str) -> Vec<u8> {
    let offer = self
        .state
        .current_offer
        .clone()
        .expect("no wl_data_offer delivered (is this client focused?)");
    let (read_fd, write_fd) = rustix::pipe::pipe().expect("pipe");
    offer.receive(mime.to_string(), write_fd.as_fd());
    drop(write_fd); // keep only the source's dup of the write end
    self.roundtrip();
    use std::io::Read;
    let mut buf = Vec::new();
    std::fs::File::from(read_fd).read_to_end(&mut buf).expect("read selection");
    buf
}
```
