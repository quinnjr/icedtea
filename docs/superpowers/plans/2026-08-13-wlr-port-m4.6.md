# wlr port M4.6 — Clipboard daemon + minimal GTK4 shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the project's first shell — a GTK4 layer-shell panel with a window/workspace taskbar and a clipboard popover — plus an `icedtea-clipboard` daemon that owns `wlr-data-control` and serves clipboard history over D-Bus.

**Architecture:** Two new crates. `icedtea-clipboard` (headless) is a `zwlr_data_control` Wayland client with a pure bounded history reducer, serving `org.icedtea.Clipboard` over zbus, threaded exactly like the compositor's `dbus.rs` (Wayland loop + zbus, channel-bridged). `icedtea-shell` (GTK4) is a zbus client of both `org.icedtea.WM` and `org.icedtea.Clipboard`; all widgets live on the GTK main thread and all D-Bus on a worker, bridged by a glib channel. Both connect to the same compositor (daemon via data-control, shell via gtk4-layer-shell).

**Tech Stack:** Rust, zbus 5, zvariant 5, wayland-client 0.31, wayland-protocols-wlr 0.3, gtk4 (gtk4-rs), gtk4-layer-shell, glib, crossbeam-channel. Tests reuse the M4.1 compositor harness (`compositor/tests/support`).

```rust
impl History {
    pub fn new(max: usize) -> Self { History { items: Vec::new(), max, next_id: 1 } }

    pub fn push(&mut self, kind: ClipKind, mime: String, bytes: &[u8], source_app: Option<String>) -> Change {
        // Dedupe: identical bytes+mime as the newest UNPINNED head is a no-op.
        if let Some(head) = self.items.iter().find(|i| !i.entry.pinned) {
            if head.mime == mime && head.bytes == bytes { return Change::Unchanged; }
        }
        let id = self.next_id; self.next_id += 1;
        let preview = make_preview(kind, bytes);
        let entry = ClipEntry { id, kind, preview, mime: mime.clone(), pinned: false, source_app };
        // Insert after the pinned block, at the front of the unpinned block.
        let insert_at = self.items.iter().take_while(|i| i.entry.pinned).count();
        self.items.insert(insert_at, Item { entry, mime, bytes: bytes.to_vec() });
        self.evict();
        Change::Changed
    }

    fn evict(&mut self) {
        let mut unpinned = 0;
        self.items.retain(|i| {
            if i.entry.pinned { return true; }
            unpinned += 1;
            unpinned <= self.max
        });
    }

    pub fn pin(&mut self, id: u64, on: bool) -> Change {
        let Some(pos) = self.items.iter().position(|i| i.entry.id == id) else { return Change::Unchanged };
        if self.items[pos].entry.pinned == on { return Change::Unchanged; }
        self.items[pos].entry.pinned = on;
        // Re-sort: pinned block first (both blocks keep relative order).
        self.items.sort_by_key(|i| !i.entry.pinned);
        Change::Changed
    }

    pub fn remove(&mut self, id: u64) -> Change {
        let before = self.items.len();
        self.items.retain(|i| i.entry.id != id);
        if self.items.len() == before { Change::Unchanged } else { Change::Changed }
    }

    pub fn clear(&mut self) -> Change {
        let before = self.items.len();
        self.items.retain(|i| i.entry.pinned);
        if self.items.len() == before { Change::Unchanged } else { Change::Changed }
    }

    pub fn snapshot(&self) -> Vec<ClipEntry> { self.items.iter().map(|i| i.entry.clone()).collect() }

    pub fn bytes_for(&self, id: u64) -> Option<(String, Vec<u8>)> {
        self.items.iter().find(|i| i.entry.id == id).map(|i| (i.mime.clone(), i.bytes.clone()))
    }
}

fn make_preview(kind: ClipKind, bytes: &[u8]) -> String {
    match kind {
        ClipKind::Image => "[image]".into(),
        _ => {
            let s = String::from_utf8_lossy(bytes);
            let t: String = s.chars().take(80).collect();
            t.replace('\n', " ").trim().to_string()
        }
    }
}
```

use icedtea_contract::{ClipEntry, ClipKind};
use wayland_client::protocol::{wl_registry, wl_seat};
use wayland_client::{Connection, Dispatch, QueueHandle, event_created_child};
use wayland_protocols_wlr::data_control::v1::client::{
    zwlr_data_control_device_v1 as dev, zwlr_data_control_manager_v1 as mgr,
    zwlr_data_control_offer_v1 as offer, zwlr_data_control_source_v1 as src,
};
use crate::history::{Change, History};

pub enum Command { Activate(u64), Pin(u64, bool), Remove(u64), Clear }

const MIMES: &[&str] = &["text/plain;charset=utf-8", "text/plain", "text/uri-list"];

struct App {
    manager: Option<mgr::ZwlrDataControlManagerV1>,
    seat: Option<wl_seat::WlSeat>,
    device: Option<dev::ZwlrDataControlDeviceV1>,
    // The offer currently advertised as the selection, and its mimes.
    offer: Option<offer::ZwlrDataControlOfferV1>,
    offer_mimes: Vec<String>,
    // A source WE set (re-paste), so its echoed selection is not re-captured.
    our_source: Option<src::ZwlrDataControlSourceV1>,
    our_serve: Option<(String, Vec<u8>)>,
    history: History,
    changes: Sender<Change>,
    // Set when a selection offer arrives; drained by the run loop to receive+push.
    pending_capture: bool,
}
```

Implement:
- `wl_registry` Dispatch: bind `zwlr_data_control_manager_v1` and `wl_seat`; create the device once both exist.
- `dev` Dispatch (+ `event_created_child!` for `data_offer` → `offer`): on `DataOffer` reset `offer_mimes`; on `Selection(Some(o))` store `offer = o`, set `pending_capture = true`; on `Selection(None)` clear.
- `offer` Dispatch: collect `Offer{mime}` into `offer_mimes`.
- `src` Dispatch: on `Send{mime_type, fd}` if it matches `our_serve.0`, write `our_serve.1` to `fd` and drop; on `Cancelled` clear `our_source`.
- A `capture()` step run from the loop when `pending_capture`: pick the best of `MIMES` present in `offer_mimes`; if the current offer is the one WE set (identity match against `our_source`'s echoed offer — guard by a flag set right after `set_selection`), skip; else `receive(mime, pipe)`, roundtrip, read the bytes, `history.push(kind_of(mime), mime, &bytes, None)`, and `changes.send` if `Changed`.
- `activate(id)`: `bytes_for(id)` → create `our_source`, `offer(mime)`, `device.set_selection(Some(&source))`, store `our_serve`, set the self-set guard.

**Self-capture guard (spec risk):** after `set_selection` with our own source, the compositor echoes a `Selection` event whose offer is backed by our source. Detect it by a one-shot `expect_own_selection: bool` set in `activate` and cleared when the next `Selection` arrives; while set, skip `history.push`. use crossbeam_channel::Sender;
use icedtea_contract::{ClipEntry, CLIP_BUS_NAME, CLIP_PATH};
use std::sync::{Arc, Mutex};
use crate::manager::Command;

pub struct ClipboardService {
    // The service answers get_history from a shared snapshot the run loop keeps
    // fresh; commands go to the Wayland thread via `commands` + `wake`.
    snapshot: Arc<Mutex<Vec<ClipEntry>>>,
    commands: Sender<Command>,
    wake: std::os::unix::net::UnixStream,
}

#[zbus::interface(name = "org.icedtea.Clipboard")]
impl ClipboardService {
    fn get_history(&self) -> Vec<ClipEntry> { self.snapshot.lock().unwrap().clone() }
    fn activate(&self, id: u64) { self.push(Command::Activate(id)); }
    fn pin(&self, id: u64, on: bool) { self.push(Command::Pin(id, on)); }
    fn remove(&self, id: u64) { self.push(Command::Remove(id)); }
    fn clear(&self) { self.push(Command::Clear); }

    #[zbus(signal)]
    async fn history_changed(ctx: &zbus::object_server::SignalEmitter<'_>) -> zbus::Result<()>;
}
```

`push` sends the command and nudges `wake` (mirror `WmInterface::send`). The `snapshot` `Arc<Mutex>` is updated by the run loop after every `Change`, and `spawn` emits `history_changed` on each `Change`.
