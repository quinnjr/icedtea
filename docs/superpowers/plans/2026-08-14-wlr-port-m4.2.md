# wlr port M4.2 — Drag-and-drop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pointer- and touch-driven drag-and-drop between Wayland clients, with a virtual-pointer protocol and a test-only touch injector so it is fully automated headlessly.

**Architecture:** wlroots owns the drag state machine and the source→destination transfer. The `wlr` crate wires the seat's `request_start_drag` (serial-validated → `wlr_seat_start_pointer_drag`/`start_touch_drag`) and `start_drag` (a `wlr_scene_drag_icon` node), and adds `create_virtual_pointer_manager` + a test-only touch injector so a headless test can start and move a drag with authentic serials. The compositor only creates the global at boot.

**Tech Stack:** Rust, wlroots 0.20 via the `wlr` crate, wayland-client / wayland-protocols(-misc) for the test clients. Tests reuse the `icedtea-harness` crate.

**Spec:** `docs/superpowers/specs/2026-08-14-wlr-port-m4.2-drag-and-drop-design.md`

```rust
// RuntimeInner field (near virtual_keyboard_manager):
pub(crate) virtual_pointer_manager:
    RefCell<Option<NonNull<sys::wlr_virtual_pointer_manager_v1>>>,
// init: virtual_pointer_manager: RefCell::new(None),

pub fn create_virtual_pointer_manager(&self, display: &Display) -> Result<()> {
    if self.inner.virtual_pointer_manager.borrow().is_some() {
        return Err(Error::Operation("Runtime::create_virtual_pointer_manager called twice"));
    }
    // SAFETY: display-owned, never freed by this crate.
    let raw = unsafe { sys::wlr_virtual_pointer_manager_v1_create(display.as_ptr()) };
    let raw = NonNull::new(raw).ok_or(Error::Create("wlr_virtual_pointer_manager_v1_create"))?;
    *self.inner.virtual_pointer_manager.borrow_mut() = Some(raw);
    Ok(())
}
pub(crate) fn virtual_pointer_manager_ptr(&self) -> Option<NonNull<sys::wlr_virtual_pointer_manager_v1>> {
    *self.inner.virtual_pointer_manager.borrow()
}
```

- [ ] **Step 2: Add `on_new_virtual_pointer`** (backend.rs), mirroring `on_new_virtual_keyboard` but for the pointer path. The `new_virtual_pointer` event data is a `wlr_virtual_pointer_v1_new_pointer_event`; its `.new_pointer` is the `wlr_virtual_pointer_v1`, whose embedded `.pointer` is a `wlr_pointer` with a `.base` input device. **Verify the event struct name/field** (`grep -n 'wlr_virtual_pointer_v1_new_pointer_event' $(find target -name bindings.rs|head -1)`); if the event is the bare `wlr_virtual_pointer_v1`, cast to that instead.

```rust
unsafe extern "C" fn on_new_virtual_pointer<S: Handlers>(l: *mut sys::wl_listener, data: *mut core::ffi::c_void) {
    // SAFETY: linked into wlr_virtual_pointer_manager_v1.events.new_virtual_pointer.
    unsafe {
        let bound = bound_of(l);
        let session = (*bound).session.cast::<Session<'_, S>>();
        let event = data.cast::<sys::wlr_virtual_pointer_v1_new_pointer_event>();
        let vp = (*event).new_pointer;
        let pointer = &raw mut (*vp).pointer;
        let device = &raw mut (*vp).pointer.base;
        let runtime = (*session).runtime;

        let alive = Rc::new(Cell::new(true));
        let destroy = Registration::link_bare(&raw mut (*device).events.destroy, on_input_destroy::<S>, (*bound).session, &raw const *alive);
        if let Some(cursor) = runtime.cursor_ptr() {
            sys::wlr_cursor_attach_input_device(cursor.as_ptr(), device);
        }
        let p_nn = NonNull::new_unchecked(pointer);
        runtime.record_pointer(p_nn);
        let listeners = vec![
            Registration::link_bare(&raw mut (*pointer).events.motion, on_pointer_motion::<S>, (*bound).session, &raw const *alive),
            Registration::link_bare(&raw mut (*pointer).events.motion_absolute, on_pointer_motion_absolute::<S>, (*bound).session, &raw const *alive),
            Registration::link_bare(&raw mut (*pointer).events.button, on_pointer_button::<S>, (*bound).session, &raw const *alive),
        ];
        (*session).inputs.borrow_mut().insert(device as usize, InputDevice { keyboard: None, pointer: Some(p_nn), _destroy: destroy, _listeners: listeners, alive });
        update_seat_capabilities(runtime);
    }
}
```

Match the `InputDevice` field order to the current struct (M4.1 put `alive` last).

## Task 2: wlr — drag-and-drop wiring

**Files:** Modify `crates/wlr/src/backend.rs`.

**Interfaces:**
- Produces: honoring `request_start_drag` (pointer + touch) and rendering the drag icon. Consumes: `runtime.seat_ptr()`, the overlay band ptr accessor (grep for how M3's `add_rect_in_band(Overlay)` reaches the overlay tree — reuse that band pointer for the drag-icon parent), `bound_of`/`Session`.

- [ ] **Step 1: `on_request_start_drag`** (backend.rs) — validate the grab serial, then start the drag. The event is `wlr_seat_request_start_drag_event { drag, origin, serial }`. Pointer vs touch: check `(*drag).grab_type` or try pointer-grab validation first.

```rust
unsafe extern "C" fn on_request_start_drag<S: Handlers>(l: *mut sys::wl_listener, data: *mut core::ffi::c_void) {
    // SAFETY: linked into wlr_seat.events.request_start_drag; data is a live event.
    unsafe {
        let bound = bound_of(l);
        let session = (*bound).session.cast::<Session<'_, S>>();
        let event = data.cast::<sys::wlr_seat_request_start_drag_event>();
        let Some(seat) = (*session).runtime.seat_ptr() else { return };
        let seat = seat.as_ptr();
        // Pointer drag if the serial is a valid pointer grant.
        if sys::wlr_seat_validate_pointer_grab_serial(seat, (*event).origin, (*event).serial) {
            sys::wlr_seat_start_pointer_drag(seat, (*event).drag, (*event).serial);
            return;
        }
        // Otherwise try touch.
        let mut point: *mut sys::wlr_touch_point = std::ptr::null_mut();
        if sys::wlr_seat_validate_touch_grab_serial(seat, (*event).origin, (*event).serial, &raw mut point) {
            sys::wlr_seat_start_touch_drag(seat, (*event).drag, (*event).serial, point);
        }
        // Invalid serial: ignore (the drag never starts). Negative test pins this.
    }
}
```

```rust
/// Test-only: synthesize a touch point so a headless test can drive a touch
```
