# wlr 0.20.34 Wire-Up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Consume published `wlr` 0.20.34 in icedtea with real handler behavior, proven by harness round-trip e2e.

**Architecture:** Bump first and prove the jump is clean, then wire the six new output-handler methods plus two manager globals onto existing flows (layout, disabled-outputs, boot block), then prove each with headless round-trip tests. No render-loop, scene-graph, or protocol-semantics changes.

**Tech Stack:** Rust, wlroots 0.20 via `wlr` 0.20.34, icedtea headless harness (`harness/src`, `compositor/tests`).

**Spec:** `docs/superpowers/specs/2026-09-12-wlr-0-20-34-wireup-design.md`

## Global Constraints

- Worktree `.worktrees/wlr-034-wireup`, branch `feature/wlr-0.20.34-wireup` (already created off `develop` tip `0be7ec1`).
- Never `unwrap`/`expect`/`assert!`/index inside `OutputHandler` bodies (aborts through C) — record in `State`, assert after the run.
